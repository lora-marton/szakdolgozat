VideoFeedback.tsx — Comparison Video Player
=============================================

Custom video player with timeline markers that highlight the dancer's
worst moments. Renders the side-by-side comparison video generated by
the backend's VideoFeedback pipeline.


================================================================================
Props (VideoFeedbackProps)
================================================================================

  videoUrl          string                      Relative path to the video
  timelineMarkers   { time, label }[] (opt.)    Marker positions with labels


================================================================================
Helper
================================================================================

  formatTime(timeInSeconds) -> string
  ───────────────────────────────────

    Converts seconds to MM:SS format. Returns "00:00" for NaN input.
    Used for the current time and duration displays, and for marker
    tooltips.


================================================================================
State and Refs
================================================================================

  fullUrl       string              Built once from buildVideoUrl(videoUrl)
  videoRef      ref to <video>      Direct access to the HTML video element
  isPlaying     boolean             Tracks play/pause state
  currentTime   number              Current playback position in seconds
  duration      number              Video length, defaults to 1 (avoids /0)


================================================================================
useEffect — Video Loading
================================================================================

  Triggers on fullUrl change. Calls videoRef.current.load() to force the
  browser to fetch video metadata (duration, dimensions) before the user
  hits play. Without this, duration would remain unknown until playback
  starts.


================================================================================
Event Handlers
================================================================================

  togglePlay          Play/pause toggle via the video element API
  handleTimeUpdate    Syncs currentTime state with video position (fires
                      continuously during playback)
  handleLoadedMetadata  Stores video duration once metadata loads
  handleVideoEnd      Resets isPlaying when video reaches the end
  handleSliderChange  Seeks to the slider position when user drags it


================================================================================
Timeline Markers
================================================================================

  Maps timelineMarkers into MUI Slider marks format. Each mark renders as:

    - An 8px circle dot positioned on the slider track
    - A Tooltip showing "MM:SS — label" on hover
    - Click handler that seeks to marker.time and auto-plays if paused

  e.stopPropagation() on the dot click prevents it from also triggering
  the Slider's own onChange handler. The Slider's built-in mark styling
  is hidden (backgroundColor: 'transparent') so only the custom dots
  are visible.


================================================================================
Layout
================================================================================

  Fade (600ms) → Paper (bordered, full width)
    │
    ├─ Title row: OndemandVideoIcon + "Comparison Video"
    │
    ├─ Video container (black background, rounded, click-to-play)
    │   └─ <video> element with event handlers
    │
    ├─ Controls row:
    │   ├─ Play/Pause IconButton
    │   ├─ Current time (MM:SS)
    │   ├─ Slider with marker dots
    │   └─ Total duration (MM:SS)
    │
    └─ Caption (italic, secondary color)
        Explains the video layout: teacher left, student right,
        ghost skeleton, marker dots, left/right orientation


================================================================================
Design Notes
================================================================================

  - The videoUrl prop is a relative path (e.g. '/feedback/video?session_id=...')
    which buildVideoUrl() prefixes with BASE_URL. This keeps the component
    decoupled from the backend address.

  - Both click-on-video and the play button call togglePlay(). The video
    element also has onPlay/onPause listeners that sync isPlaying state
    independently — this handles edge cases like browser autoplay policies
    or keyboard shortcuts.

  - The caption text is part of the component rather than external
    documentation because users need context to understand the
    side-by-side layout while watching.
