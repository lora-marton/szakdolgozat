Lines 24–45: lifespan() — Application Lifecycle Hook
------------------------------------------------------
This is a standalone async context manager passed to FastAPI. It runs once at
app startup (everything before yield) and once at shutdown (after yield).

- Line 24: @asynccontextmanager decorator turns this async generator into a context manager.
- Line 25: The function receives the FastAPI app instance as its argument.
- Lines 31–34: On Windows (sys.platform == "win32"), imports signal and resets SIGINT handling to the system default (SIG_DFL). Without this, Ctrl+C does not stop the uvicorn server on Windows.
- Line 36: Gets the currently running asyncio event loop.
- Lines 38–42: Defines _suppress_proactor_errors, a custom exception handler that silently ignores ConnectionResetError (a known spurious error from Windows' ProactorEventLoop) and delegates everything else to the default handler.
- Line 44: Installs the custom exception handler on the event loop.
- Line 45: yield — the app runs between startup and shutdown. Nothing runs after yield, so there is no shutdown cleanup.

This function is NOT part of the FeedbackSender class because it is a framework-level
lifecycle hook tied to the FastAPI app, not business logic.
