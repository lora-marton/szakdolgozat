config/ subpackage — Explanation
=================================

The config subpackage lives in model/config/ and contains four frozen dataclasses
that hold all tunable parameters for the dance comparison pipeline. Each class is
in its own file with a default instance. The __init__.py re-exports everything so
imports like "from model.config import DEFAULT_EXTRACTION_CONFIG" work.


================================================================================
extraction_config.py — ExtractionConfig
================================================================================

Imports:
  - dataclass (from dataclasses): Decorator that auto-generates __init__, __repr__, etc.
  - mediapipe as mp: Google's pose estimation library — used in create_landmarker_options().

Class Declaration:
  - @dataclass(frozen=True): Makes instances immutable — fields can't be changed after creation.
    This prevents accidental config mutation during a pipeline run.

Fields:

  model_path (str, 'model/pose_landmarker_heavy.task')
    Path to the MediaPipe pose landmarker model file (.task format, ~30MB).

  target_fps (float, 60.0)
    Target frame rate for resampling both videos. Both teacher and student
    videos are resampled to this rate so frame-to-frame comparisons are fair.

  output_fps (float, 30.0)
    Frame rate used for the feedback video output and for converting frame
    indices to timestamps. Lower than target_fps to keep file size manageable.

  target_torso_px (float, 40.0)
    Torso length in normalized pixel space. All poses are scaled so the torso
    is exactly this length, making comparison size-independent.

  target_mask_size (tuple, (256, 256))
    Resolution of the segmentation mask in pixels.

  norm_center (tuple, (128, 128))
    Origin point for normalization — center of the 256x256 mask.

  min_pose_detection_confidence (float, 0.8)
    Minimum confidence to accept a new pose detection.

  min_pose_presence_confidence (float, 0.8)
    Minimum confidence that a person is present.

  min_tracking_confidence (float, 0.8)
    Minimum confidence for frame-to-frame tracking.
    All set to 0.8 = fairly strict, reduces false/jittery detections.

  filter_min_cutoff (float, 1.0)
    Baseline smoothing frequency for the One Euro Filter.
    Lower = more smoothing when stationary.

  filter_beta (float, 20.0)
    Speed coefficient for the One Euro Filter. Higher values allow less
    smoothing during fast movements — critical for preserving fast dance moves.

  pose_connections (tuple)
    Tuple of (joint_a, joint_b) pairs defining skeleton bones for visualization.
    Groups: arms (shoulder→elbow→wrist), torso (shoulders + hips),
    legs (hip→knee→ankle).

Method:

  create_landmarker_options() -> PoseLandmarkerOptions
    Constructs a MediaPipe PoseLandmarkerOptions object using this config's
    values. Sets running_mode to VIDEO (frame-by-frame with tracking),
    output_segmentation_masks=True for body silhouette masks.

Instance:
  DEFAULT_EXTRACTION_CONFIG — pre-created with all default values.


================================================================================
comparison_config.py — ComparisonConfig
================================================================================

Imports:
  - dataclass, field (from dataclasses): field is needed for mutable default
    values (dicts), since dataclasses require default_factory for mutable types.

Class Declaration:
  - @dataclass(frozen=True): Same immutable pattern as ExtractionConfig.

Fields:

  Overall Scoring Weights:
    weight_skeleton (float, 0.55)  — 55% of the final score from skeleton.
    weight_trajectory (float, 0.15) — 15% from trajectory.
    weight_mask (float, 0.30)      — 30% from mask.
    These three sum to 1.0.

  Skeleton Sub-Weights:
    weight_angles (float, 0.80)    — 80% of skeleton score from joint angles.
    weight_cog (float, 0.20)       — 20% from center-of-gravity.

  Exponential Decay Parameters:
    angle_sigma (float, 35.0) — Degrees. Controls how harshly angle errors
      are penalized. A 35° error gives approximately 37% score.
    cog_sigma (float, 0.08) — Normalized coordinates (0-1 range). Same
      concept for center-of-gravity distance.

  dtw_joints (tuple)
    The 12 main body joints used for Dynamic Time Warping alignment:
    Shoulders (11,12), elbows (13,14), wrists (15,16),
    hips (23,24), knees (25,26), ankles (27,28).

  dtw_window_size (int, 120)
    Sakoe-Chiba band width in frames. Limits how far apart matched frames
    can be (2 seconds at 60fps). Prevents pathological alignments.

  joint_angles (tuple)
    16 joint angle definitions as (parent, joint, child) landmark triplets.
    The angle is measured at the middle joint between the two outer joints.

    Index  Triplet         Name
    ─────  ──────────────  ────────────────────
     0     (11, 13, 15)    left_elbow
     1     (12, 14, 16)    right_elbow
     2     (23, 25, 27)    left_knee
     3     (24, 26, 28)    right_knee
     4     (13, 11, 23)    left_shoulder
     5     (14, 12, 24)    right_shoulder
     6     (11, 23, 25)    left_hip
     7     (12, 24, 26)    right_hip
     8     (13, 15, 19)    left_wrist
     9     (14, 16, 20)    right_wrist
    10     (25, 27, 31)    left_ankle
    11     (26, 28, 32)    right_ankle
    12     (12, 11, 23)    left_inner_shoulder
    13     (11, 12, 24)    right_inner_shoulder
    14     (11, 23, 24)    left_inner_hip
    15     (12, 24, 23)    right_inner_hip

    The "inner" angles capture torso shape — how the chest opens/closes and
    how the pelvis tilts side to side. These are important for detecting
    upper-body lean and hip sway.

  joint_tolerances (dict, via default_factory)
    Per-joint tolerance buffers in degrees. Errors within this buffer are
    considered personal style variation, not mistakes. 16 individual entries:
      Elbows: 15°, Knees: 15°
      Shoulders: 10°, Hips: 10°
      Wrists: 20°, Ankles: 20°
      Inner shoulders: 10°, Inner hips: 10°

  cog_weights (dict, via default_factory)
    Biomechanics-based body segment weights for computing center of gravity.
    Hips carry the most weight (0.15 each) as the body's center of mass.
    Head (0.08), shoulders (0.06), knees (0.06), elbows (0.03),
    wrists/ankles (0.02). Weights approximate real body proportions.

  visibility_threshold (float, 0.5)
    Minimum landmark visibility to consider a joint angle reliable.
    Used by SkeletonMetrics._compare_angles to filter out frames where
    landmarks are off-screen or occluded.

  mask_binary_threshold (int, 128)
    Threshold for converting grayscale segmentation mask to binary.

  efd_harmonics (int, 7)
    Number of Fourier harmonics for contour smoothing.
    7 harmonics capture body shape while ignoring clothing wrinkles.

  efd_contour_points (int, 200)
    Number of points in the reconstructed smooth contour.

  dtm_sigma (float, 25.0)
    Distance Transform Mapping decay width in pixels. Controls how sharply
    misaligned silhouette regions are penalized.

  flow_winsize (int, 15)
    Farneback optical flow averaging window size in pixels.

  Mask Sub-Weights:
    weight_shape (float, 0.70) — 70% of mask score from DTM shape comparison.
    weight_energy (float, 0.30) — 30% from optical flow motion energy.

  Trajectory Sub-Weights:
    trajectory_weight_direction (float, 0.75) — 75% from direction similarity.
    trajectory_weight_speed (float, 0.25) — 25% from speed ratio.

Instance:
  DEFAULT_COMPARISON_CONFIG — pre-created with all default values.


================================================================================
feedback_config.py — FeedbackConfig
================================================================================

Imports:
  - dataclass (from dataclasses): Same decorator pattern.

Class Declaration:
  - @dataclass(frozen=True): Immutable config, same pattern.

Fields:

  joint_warn_threshold (float, 60.0)
    Joint scores below 60% trigger a warning in the feedback.

  direction_warn_threshold (float, 60.0)
    Direction similarity scores below 60% trigger a trajectory warning.
    On the 0-100 scale, consistent with all other thresholds.

  mask_warn_threshold (float, 60.0)
    Mask scores below 60% trigger a silhouette warning.

  praise_threshold (float, 75.0)
    Component scores above 75% get positive feedback.

  min_marker_gap (float, 1.0)
    Minimum time gap in seconds between timeline markers. Prevents markers
    from clustering at the same moment in the feedback video.

  energy_low_threshold (float, 0.6)
    Student/teacher energy ratio below 0.6 triggers "less energetic" warning.

  energy_high_threshold (float, 1.4)
    Student/teacher energy ratio above 1.4 triggers "exaggerated" warning.
    Asymmetric with the low threshold because under-dancing is more common.

  timing_warn_threshold (float, 0.67)
    Normalized DTW cost above this value triggers a timing/rhythm warning.

  timing_praise_threshold (float, 0.60)
    Normalized DTW cost at or below this value triggers timing praise.

Instance:
  DEFAULT_FEEDBACK_CONFIG — pre-created with all default values.


================================================================================
preprocessor_config.py — PreprocessorConfig
================================================================================

Imports:
  - dataclass (from dataclasses): Same decorator pattern.

Class Declaration:
  - @dataclass(frozen=True): Immutable config, same pattern.

Fields:

  audio_sample_rate (int, 22050)
    Sample rate for audio cross-correlation. Standard audio analysis rate.

  motion_threshold_ratio (float, 0.15)
    Fraction of maximum motion energy to count as "active". Frames below
    15% of peak energy are considered idle.

  min_active_duration (int, 10)
    Minimum consecutive active frames required. Short bursts of motion
    below 10 frames are ignored as noise.

  active_window_ratio (float, 0.7)
    Fraction of frames within the sliding window that must be above
    threshold. Allows brief dips in energy (e.g. a pose hold for 2-3
    frames) without breaking the detection.

Instance:
  DEFAULT_PREPROCESSOR_CONFIG — pre-created with all default values.


================================================================================
__init__.py — Re-exports
================================================================================

  Re-exports all four config classes and their default instances:
    ExtractionConfig, DEFAULT_EXTRACTION_CONFIG
    ComparisonConfig, DEFAULT_COMPARISON_CONFIG
    FeedbackConfig, DEFAULT_FEEDBACK_CONFIG
    PreprocessorConfig, DEFAULT_PREPROCESSOR_CONFIG

  This allows imports from model.config directly without needing to know
  which subfile a config lives in.
